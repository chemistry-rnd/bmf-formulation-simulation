# Кластеры Сколково и приоритеты

> Какой кластер выбрать для проекта. Подробные приоритеты каждого кластера.

## Как выбрать кластер

1. Определите основную технологическую область вашего проекта
2. Найдите **конкретный подпункт** в приоритетах кластера (недостаточно просто "ИТ" — нужно "5.1.4 — Нейротехнологии и ИИ")
3. Если проект на стыке — выберите кластер, где подпункт точнее описывает вашу технологию
4. Загрузите полный документ приоритетов и проверьте соответствие

## Кластер 2: Биомед (Биологические и медицинские технологии)

**URL:** https://sk.ru/foundation/clusters/biomed/
**Приоритеты (приказ №59-пр от 18.03.2020 + №98-Пр от 27.05.2021):** https://dochub.sk.ru/news/m/wiki/24011/download.aspx

### Медицинские технологии (раздел 4)

| Подпункт | Направление |
|----------|------------|
| 4.1 | Диагностика и визуализация (рентген/КТ, МРТ, УЗИ) |
| 4.2 | Терапевтические устройства и реабилитация (лучевая терапия, хирургия, нейроинтерфейсы, медицинская робототехника) |
| 4.3 | Диагностика in vitro (ПЦР, ИФА, лабораторное оборудование, биобанки) |
| 4.4 | Лекарственные препараты (иммунотерапия, противоинфекционные, онкология, кардиология, ЦНС) |
| 4.5 | Омиксные технологии (секвенирование, биоинформатика, персонализированная медицина) |
| 4.6 | Клеточная и тканевая терапия (стволовые клетки, биоматериалы, биопечать) |
| 4.7 | ИТ в медицине (СППР, телемедицина, МИС) |

### Биотехнологии в с/х и промышленности (раздел 6) — ДЛЯ ПИЩЕВЫХ ТЕХНОЛОГИЙ

| Подпункт | Направление | Релевантность для food tech |
|----------|------------|---------------------------|
| 6.1 | Генетика и селекция | Низкая |
| 6.2 | Вакцины, корма, агрохимия | Низкая |
| 6.3 | Цифровые технологии в с/х | Низкая |
| 6.4 | Хранение и переработка сырья, биоремедиация | **Средняя** — если технология связана с хранением |
| **6.5** | **Промышленная биотехнология** (ферментация, аминокислоты, витамины) | **Высокая** — если используется ферментация / закваски |
| **6.6** | **Пищевые технологии** (новые продукты, упаковка, хранение) | **Высокая** — основной подпункт для food tech |
| 6.7 | Инженерные решения для с/х | Низкая |
| 6.8 | Косметика | Низкая |
| **6.9** | **Парафармацевтика** (функциональное питание, спортпит) | **Средняя** — если продукт функциональный |
| 6.10 | Домашние животные | Низкая |

> **VivaCrumb** (clean-label shelf-life для хлебопечения) → **6.6 (пищевые технологии)** или **6.5 (промышленная биотехнология)**, если ключевой элемент — ферментация / культуры.

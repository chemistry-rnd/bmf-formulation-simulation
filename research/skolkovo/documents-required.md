# Необходимые документы для Сколково

> Что подготовить для подачи заявки и получения статуса участника.

---

## Юридические требования к соискателю

| Требование | Детали |
|-----------|--------|
| Организационная форма | **Юридическое лицо**, зарегистрированное в РФ |
| ОКВЭД | Класс **72** "Научные исследования и разработки" — основной или дополнительный |
| Учредители | Нет иностранных юрлиц из **офшорных зон** (перечень Минфина РФ) |
| Выручка учредителя | Мажоритарный учредитель (>50% голосов) — выручка < **4 млрд руб./год** |
| Адрес | Юридический адрес в РФ (не обязательно в Сколково) |
| Соответствие законодательству | ФЗ №244-ФЗ от 28.09.2010, Стратегия НТР РФ |

---

## Этап 1: Документы для экспертизы проекта

### Обязательно

- **Заполненная заявка** на экспертизу во всех разделах
  - Подаётся через ЛК: https://lk.sk.ru/candidate-request/
  - Включает описание технологии, рынка, команды
  - Привязка к кластеру и подпункту приоритетов

### Рекомендуется приложить

- Презентация проекта (10-15 слайдов)
- Протоколы испытаний / отчёты НИОКР
- Патенты / заявки на патенты
- Публикации команды
- Отзывы клиентов / Letter of Intent
- Финансовая модель

---

## Этап 2: Документы для получения статуса

> Подаются **после** положительного решения экспертизы. Протокол действует 6 месяцев.

1. **Заявление соискателя** — подписано **УКЭП** (усиленной квалифицированной электронной подписью) руководителя организации
2. **Файл устава** — полученный из налоговой в электронном виде, с **ЭЦП налоговой**
3. **Протокол экспертной коллегии** — прикрепляется автоматически

---

## Требования к уставу

- Должен соответствовать **шаблону Фонда**
- Шаблон для обычных компаний: https://sk.ru/documents/790/
- Шаблон для компаний в других инноцентрах: https://sk.ru/documents/2811/
- **До регистрации** в налоговой можно отправить проект устава на предварительную проверку: **UstavSk@sk.ru** (указать номер заявки)

## Чеклист подготовки документов

- [ ] ОКВЭД 72 добавлен в ЕГРЮЛ
- [ ] Устав по шаблону Фонда (проверен на UstavSk@sk.ru)
- [ ] УКЭП оформлена на руководителя
- [ ] Нет офшорных учредителей
- [ ] Выручка мажоритарного учредителя < 4 млрд руб./год
- [ ] Заявка заполнена во всех разделах
- [ ] Указан конкретный подпункт приоритетов кластера

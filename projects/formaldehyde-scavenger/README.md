# Formaldehyde Scavenger

Technology-description workspace for treatment of fresh particleboard/MDF cuts created during on-site furniture installation.

Project-specific source material and requirements are kept here. Chemistry computation/experimental implementation may live in a separate specialist repository; this folder owns the inputs and document-generation state used by R&D Forge.

## Data provenance

`input/` is only user-provided material. Research, intermediate analysis, review notes and final Technology Description produced by LLM/research agents live under `output/`. The canonical expert-facing document is `output/final-result/current.md`.

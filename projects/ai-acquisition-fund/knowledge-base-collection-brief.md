# ТЗ: Сбор knowledge base для чатбота ScaleWithAI VC

**Контекст**: Мы делаем AI-чатбот для сайта `vc.aiqarus.ru`. Бот консультирует по инвестициям в компании, где AI-обучение команд даёт кратный рост выработки. Нужна knowledge base для vector search (RAG).

**Домен**: ТОЛЬКО компании с производственным, инжиниринговым или "тяжёлым" ядром. НЕ чистое ПО. Фокус — обучение людей через AI, а не замена оборудования.

---

## Что нужно собрать

### 1. Методика фонда (из существующих файлов)
**Источник**: файлы в этом репозитории
- `projects/ai-acquisition-landing.html` — лендинг (тезис, методика K1-K4, примеры, сегменты)
- `projects/ai-acquisition-fund/scalewithai-vc-chatbot-implementation-plan.md` — архитектура и сценарии

**Задача**: нарезать на chunks по 500-1000 токенов, каждый с метаданными.

### 2. Банкротства производственных компаний
**Источник**: fedresurs.ru
**Что парсить**:
- Название компании, ИНН
- ОКВЭД (фильтр: производство, инжиниринг, логистика с физ. активами — НЕ чистое ИТ)
- Регион
- Стадия банкротства (наблюдение, конкурсное производство, торги)
- Дата публикации
- Ссылка на карточку

**Фильтр ОКВЭД**: секции B, C, D, E, F, G (кроме 62.xx и 63.xx — чистое ПО), H, J (кроме 62.xx, 63.xx)

**Формат выхода**: один MD-файл на компанию или JSON-массив

### 3. Бизнесы на продажу
**Источники**: biztorg.ru, bizzona.ru, avito бизнес
**Что парсить**:
- Название / описание
- Отрасль (фильтровать: не чистое ПО)
- Регион
- Цена
- Выручка (если указана)
- Штат (если указан)
- Ссылка
- Дата объявления

### 4. Зарплаты по ролям
**Источник**: hh.ru API (https://api.hh.ru)
**Что собрать**:
- Средние зарплаты для ролей из методики K1-K4:
  - Бухгалтер, Планировщик производства, Снабженец, Контролёр ОТК
  - Инженер-проектировщик, Менеджер по продажам, Оператор станка
  - Документовед, HR-специалист, Рекрутер
- По регионам: Москва, СПб, МО, регионы-миллионники
- Медиана, 25-й и 75-й перцентиль

**API**: GET https://api.hh.ru/vacancies?text=бухгалтер&area=1&per_page=100
(area=1 — Москва, area=2 — СПб)

### 5. Отраслевые бенчмарки
**Источник**: Росстат / ЕМИСС (fedstat.ru), открытые отчёты
**Что собрать**:
- Средняя выработка на сотрудника по отраслям (ОКВЭД секции C, F, G, H)
- Доля ФОТ в себестоимости по отраслям
- Средний штат по размеру компании
- Рентабельность по отраслям

### 6. Кейсы AI-обучения команд
**Источники**: McKinsey, BCG, Deloitte отчёты, Хабр, vc.ru
**Что собрать**:
- Кейсы внедрения AI в нетехнологических компаниях
- Фокус: обучение людей, не замена оборудования
- Результаты: рост выработки, сокращение времени, ROI
- Отраслевая привязка

## Формат каждого документа

```markdown
---
id: unique-id
source: fedresurs | biztorg | hh_api | rosstat | case_study | fund_methodology
date: 2026-03-15
topic: bankruptcy | business_for_sale | salary | benchmark | case | methodology
region: Москва | СПб | РФ | global
industry: manufacturing | engineering | logistics | back_office | mixed
tags: [банкротство, производство, пластик]
url: https://...
---

Содержание документа. Конкретные цифры, факты, без воды.
Каждый chunk — 500-1000 токенов.
```

## Важные правила

1. **Каждый документ — с датой актуальности** (`date` в метаданных)
2. **Фильтровать домен**: НЕ включать чисто софтверные компании
3. **Конкретика**: числа, регионы, ИНН — не абстрактные описания
4. **Один chunk — одна мысль**: не смешивать банкротство с зарплатами
5. **Русский язык** для данных, метаданные — латиницей

## Куда складывать

```
projects/ai-acquisition-fund/knowledge-base/
├── methodology/          ← нарезка из лендинга и плана
├── bankruptcies/         ← fedresurs данные
├── businesses-for-sale/  ← biztorg, bizzona
├── salaries/             ← hh.ru данные
├── benchmarks/           ← росстат, ЕМИСС
└── cases/                ← кейсы AI-обучения
```

## Приоритет

1. **Сначала**: methodology (нарезка существующего — 30 мин)
2. **Потом**: salaries через hh.ru API (простой парсинг — 1 час)
3. **Потом**: bankruptcies через fedresurs (сложнее, anti-bot — 2 часа)
4. **Потом**: cases (ручной поиск + парсинг статей)
5. **Последнее**: benchmarks, businesses-for-sale

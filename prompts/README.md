# Библиотека промптов

Набор промптов для воспроизводимого процесса подготовки технологических описаний с помощью AI.

## Workflow проекта (4 стадии)

```
СТАДИЯ 1: ДРАФТ (для клиента)
┌─────────────────────────────────────────────────┐
│  01-initial-draft.md    → Краткий драфт         │
│  04-questionnaire.md    → Анкета (если нужны    │
│                           данные с производства) │
│  03-section-refinement  → Доработка разделов     │
│                                                  │
│  Результат: краткое описание технологии,         │
│  общие идеи, что можно внедрить, для кого.       │
│  ⚠️ Документ должен быть КОНКРЕТНЫМ, а не        │
│  "компьютерным" — реальные числа, термины,       │
│  ссылки на источники.                            │
└─────────────────────────────────────────────────┘
         ↓  Клиент одобряет проект

СТАДИЯ 2: ПОЛНАЯ ВЕРСИЯ
┌─────────────────────────────────────────────────┐
│  01-initial-draft.md    → Полное описание        │
│  03-section-refinement  → Глубокая проработка    │
│                           каждого модуля/раздела │
│  04-questionnaire.md    → Доп. анкеты для        │
│                           уточнения данных       │
│                                                  │
│  Результат: полное техническое описание          │
│  со всеми модулями, KPI, экономикой.             │
└─────────────────────────────────────────────────┘
         ↓  Отправляем 2 экспертам

СТАДИЯ 3: ЭКСПЕРТНАЯ ВЫЧИТКА (×2 эксперта)
┌─────────────────────────────────────────────────┐
│  02-expert-review.md    → Обработка замечаний    │
│                           от эксперта 1          │
│  02-expert-review.md    → Обработка замечаний    │
│                           от эксперта 2          │
│  03-section-refinement  → Доработка по           │
│                           замечаниям             │
│                                                  │
│  Чеклисты:                                       │
│  - checklists/before-expert-review.md            │
│  - checklists/after-expert-review.md             │
└─────────────────────────────────────────────────┘
         ↓  Все замечания обработаны

СТАДИЯ 4: ФИНАЛЬНАЯ ВЕРСИЯ + ДИАГРАММА
┌─────────────────────────────────────────────────┐
│  05-final-polish.md     → Финальная вычитка      │
│                                                  │
│  + Создание диаграммы технологического процесса  │
│  + Визуализация модульной архитектуры             │
│                                                  │
│  Результат: готовый документ для подачи.          │
└─────────────────────────────────────────────────┘
```

## Промпты

| Файл | Стадия | Назначение |
|------|--------|-----------|
| `01-initial-draft.md` | 1, 2 | Генерация черновика (краткого или полного) |
| `02-expert-review-response.md` | 3 | Обработка замечаний эксперта |
| `03-section-refinement.md` | 1, 2, 3 | Углублённая доработка конкретного раздела |
| `04-questionnaire-generation.md` | 1, 2 | Генерация анкеты для сбора данных |
| `05-final-polish.md` | 4 | Финальная вычитка и полировка |

## Ключевой принцип

**Документ не должен выглядеть "написанным AI".** Для этого:
- Используйте конкретный контекст из отрасли
- Конкретные фразы и термины (не общие слова)
- Числовые диапазоны с источниками
- Ссылки на стандарты, ГОСТы, публикации
- Реальные имена экспертов и организаций

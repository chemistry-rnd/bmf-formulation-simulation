# Библиотека промптов

Набор промптов для воспроизводимого процесса подготовки технологических описаний с помощью AI.

│  01-initial-draft.md    → Драфт (12 разделов)    │
│  04-questionnaire.md    → Анкета (если нужны     │
│                           данные с производства)  │
│  03-section-refinement  → Доработка разделов      │
│                                                  │
│  Вычитка (4 прохода):                            │

## Выходные форматы

Все клиентские документы проходят цепочку:

```
MD (исходник в projects/)
  → HTML (для предпросмотра в браузере)
    → PDF (для отправки клиенту)
      + TXT (Telegram-сообщение)
```

Готовые файлы сохраняются в `output/{project}/`. Папка `output/` в `.gitignore`.

## Ключевые принципы

### Документ не должен выглядеть "написанным AI"
- Конкретный контекст из отрасли
- Конкретные фразы и термины (не общие слова)
- Числовые диапазоны с источниками
- Ссылки на стандарты, ГОСТы, публикации
- Реальные имена экспертов и организаций

### Технология = направления, не обещания
- 2-4 самостоятельных направления R&D
- Каждое опирается на задел компании
- Успех по любому из них достаточен
- Защита клиента: если одно не сработает — это не провал

### Hard tech > чистый IT (для Сколково)
- Сколково ценит физические продукты: оборудование, материалы, инженерные системы
- Чисто программные проекты проходят экспертизу значительно сложнее
- Акцент на измеримые физические показатели (мг/м³, %, часы, кг)

### 4 прохода вычитки
1. Специалист отрасли — техническая корректность
2. Антидетектор AI — бюзворды, канцелярит, гладкие формулировки
3. Достоверность — ГОСТы, физ.величины, ссылки
4. Эксперт Сколково — кластер, 4 критерия, измеримость

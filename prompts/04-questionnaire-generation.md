# Промпт 04: Генерация анкеты для сбора данных

## Когда использовать

В описании есть "дыры" — не хватает данных от производства / лаборатории. Нужно сгенерировать целевую анкету для предметного специалиста.

## Промпт

```
Ты — технический консультант. Проанализируй описание технологии и сгенерируй анкету для сбора недостающих данных с производства / лаборатории.

## Текущее описание технологии

{вставьте текущую версию описания}

## Известные пробелы (если есть)

{перечислите, что именно не хватает — или напишите "определи автоматически"}

[Опционально: **Специалист:** {должность / роль, напр. "технолог хлебопечения", "руководитель лаборатории"}]
[Опционально: **Формат:** {анкета для email / вопросы для интервью / чеклист для визита на производство}]

## Инструкции

1. **Проанализируй описание** и найди:
   - Разделы с пометками [ТРЕБУЕТ ДАННЫХ] или [~]
   - Параметры без числовых значений
   - Утверждения без подтверждающих данных
   - Модули / этапы, описанные поверхностно

2. **Сгенерируй анкету** с вопросами:
   - Каждый вопрос привязан к конкретному разделу / модулю описания
   - Вопросы сформулированы так, чтобы ответ можно было вставить в описание
   - Формат ответа подсказан (число, диапазон, да/нет, таблица)
   - Приоритет: 🔴 критично / 🟡 важно / 🟢 желательно

3. **Структура анкеты:**

   ### Раздел: [Название раздела/модуля описания]

   | # | Вопрос | Формат ответа | Приоритет | Зачем нужно |
   |---|--------|--------------|-----------|-------------|
   | 1 | [...] | число / диапазон / текст | 🔴/🟡/🟢 | Для раздела X |

4. **В конце анкеты добавь:**
   - Просьбу приложить документы (протоколы, сертификаты, фото)
   - Контактные данные для уточнений
   - Дедлайн (placeholder: {дата})

5. **Тон:** Понятный неакадемическому специалисту. Без жаргона, если это не термины отрасли.
```

## Что проверить в результате

- [ ] Все пробелы в описании покрыты вопросами
- [ ] Вопросы конкретные (не "расскажите о процессе", а "какая температура на этапе X?")
- [ ] Формат ответа подсказан — специалисту понятно, что от него ждут
- [ ] Приоритеты расставлены — если времени мало, можно ответить только на 🔴

## Паттерны из практики (VivaCrumb)

- Анкета из диалога VivaCrumb содержала вопросы типа: "Какие закваски используются? Точные дозировки? Какие показатели мякиша контролируете?"
- Ключевой приём: формулировать вопросы так, чтобы ответ можно было напрямую вставить в описание
- Разделение на "минимальную" (15 мин) и "расширенную" (45 мин) версии повышает отклик
- Специалисты лучше отвечают на конкретные вопросы с примерами ответов, чем на открытые

## Контекст

**VivaCrumb** — модульная биотехнологическая платформа для продления свежести ремесленного хлеба без синтетических улучшителей и консервантов. Целевая аудитория — мини-пекарни с высоким дневным выпуском.

**5 модулей:**
- **LAB** — управляемая ферментация / закваска
- **YUD** — заварное тесто (yudane/tangzhong)
- **COOL** — режим охлаждения и окно упаковки
- **MAP** — модифицированная газовая среда (упаковка)
- **PAR** — частичная выпечка (par-bake 80/20)

**5 групп продуктов:** A (багет/чиабатта), B (тартин), C (100% рожь), D (обогащённый), E (нарезной батон)

## Паттерны для переиспользования

### 1. Workflow сессии

```
Документ + замечания эксперта
    → AI идентифицирует пробелы и задаёт вопросы
    → Пользователь даёт направление (не обязательно точные данные)
    → AI предлагает исправления с отраслевыми ориентирами
    → Разделы дорабатываются по одному
    → Когда "дыры" видны — создаётся анкета для сбора реальных данных
    → Анкета упрощается до минимума
```

### 2. Эффективные приёмы промптинга

| Приём | Пример | Почему работает |
|-------|--------|----------------|
| Полный контекст сразу | Документ + замечания в одном промпте | AI понимает масштаб и связи |
| "Давай подберём число" | "Какой % YUD правильный?" | AI предлагает отраслевой стандарт |
| "Давай погуглим" | Числа по MAP | AI цитирует конкретные источники |
| "Выбери лучший" | Два варианта LAB | Экономит время на выбор |
| "Какой диапазон честный?" | PAR хранение | Даёт реалистичный, а не маркетинговый ответ |
| "Слишком много — дай минимум" | 80 → 10 вопросов | Фокусирует на критичном |

### 3. Антипаттерны (что не сработало)

| Антипаттерн | Что случилось | Урок |
|-------------|--------------|------|
| Абстрактные задачи | "Улучши документ" | Нужно: "исправь 3 конкретных пункта" |
| Одновременная правка всего | Попытка обновить 5 модулей | Один модуль за раз = глубже |
| Генерация без данных | Числа из головы AI | Нужно: запросить сначала отраслевые источники |

## Технические детали VivaCrumb (для справки)

### Экономика (типовая московская пекарня, выручка 1 млрд руб./год)
- Списания снижаются: с ~11,6% до ~4,1%
- Доп. затраты на процесс: +25,5 млн руб./год (+2,0 руб./изделие)
- Экономия от снижения списаний: -45,2 млн руб./год
- CAPEX: ~25 млн руб. (амортизация ~5,5 млн руб./год)
- Чистый эффект: +15,8 млн руб./год, окупаемость < 1 года
- Рост валовой маржи: +1,6 п.п.

### TRL
- Текущий: TRL 5-6 (валидация в близких к производственным условиях)
- Цель: TRL 7 (живая смена + логистика) → TRL 8 (мультипекарня)

### Кластер Сколково
- **Биомед** → раздел 6 → **6.6 (пищевые технологии)** / **6.5 (промышленная биотехнология)**

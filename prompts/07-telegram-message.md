# Промпт 07: Telegram-сообщение клиенту

## Когда использовать

Стадия 1 — вместе с драфтом и запиской. Короткое сообщение для отправки в Telegram/WhatsApp, чтобы клиент понял, что ему прислали.

## Промпт

```
Напиши короткое сообщение (2-3 абзаца) для отправки клиенту в мессенджер. Сообщение сопровождает два документа: описание технологии (драфт) и записку.

## Входные данные

**Компания:** {название}

**Суть проекта (кратко):**
{что предлагаем: направления R&D, 1-2 предложения}

**Кластер Сколково:** {кластер}

**Ключевое преимущество позиции:**
{почему это сильная заявка, 1 предложение}

## Требования

- Максимум 3 абзаца, без заголовков
- Формат: обычный текст без форматирования (Telegram)
- Начать с приветствия
- Кратко: что подготовили, что изучили, что предлагаем
- Одна фраза про сильную позицию в Сколково
- Закончить просьбой посмотреть и дать обратную связь
- Без AI-бюзвордов, без канцелярита
- Тон: деловой, но не формальный — как будто пишешь человеку, которого знаешь
```

## Что проверить в результате

- [ ] Не длиннее 3 абзацев
- [ ] Нет форматирования (markdown, жирный шрифт и т.п.)
- [ ] Понятно, что прислано и зачем
- [ ] Есть призыв посмотреть и ответить
- [ ] Нет бюзвордов

## Выходной файл

Сохранить как `output/{project}/telegram-message.txt` — готов к копированию.

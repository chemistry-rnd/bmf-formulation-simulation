# Чеклист: готовность заявки в Сколково

> Проверка перед подачей заявки на экспертизу в Фонд "Сколково".

## Юридические требования

- [ ] **Юрлицо зарегистрировано в РФ** (или готово к регистрации — можно подать заявку до)
- [ ] **ОКВЭД класса 72** "Научные исследования и разработки" — основной или дополнительный
- [ ] **Нет иностранных учредителей из офшорных зон** (перечень Минфина РФ)
- [ ] **Выручка мажоритарного учредителя** (>50% голосов) < 4 млрд руб./год
- [ ] **Устав по шаблону Фонда** — проверен на UstavSk@sk.ru

## Соответствие приоритетам

- [ ] **Определён кластер**: [ ] ИТ / [ ] Биомед / [ ] Энерготех / [ ] Промтех
- [ ] **Определён конкретный подпункт** приоритетов кластера (напр. 6.6 — пищевые технологии)
- [ ] **Загружен документ приоритетов** кластера и проверено соответствие
- [ ] **Соответствие Стратегии НТР РФ** — можно указать связь

## Критерий 1: Инновационность

- [ ] Чётко описана **суть инновации** (что именно новое)
- [ ] Проведено **сравнение с аналогами** в табличном виде
- [ ] Описана **научная основа** технологии
- [ ] Указаны **публикации / патенты**, если есть
- [ ] Нет голословных утверждений — всё подтверждено данными

## Критерий 2: Коммерциализация

- [ ] Указан **объём рынка** (TAM/SAM/SOM) с источниками
- [ ] Описана **бизнес-модель** и ценообразование
- [ ] Перечислены **текущие клиенты / пилоты / LOI**
- [ ] Указана **текущая выручка** (рекомендуется от 5 млн руб./год для Fast Track)
- [ ] Проведён **конкурентный анализ**

## Критерий 3: Реализуемость

- [ ] Указана **текущая стадия** (прототип / пилот / серия)
- [ ] Описаны **проведённые эксперименты** с результатами
- [ ] Есть **дорожная карта** с конкретными сроками
- [ ] Перечислены **ресурсы** (оборудование, финансы, партнёры)
- [ ] Описаны **риски** и план их митигации

## Критерий 4: Команда

- [ ] Описаны **ключевые участники** с квалификацией
- [ ] Указан **опыт в отрасли** для каждого
- [ ] Продемонстрирован **предпринимательский потенциал**
- [ ] Перечислены **публикации и патенты** команды
- [ ] Есть **научный руководитель** с профильным опытом

## Документы

- [ ] **Заявка заполнена** во всех разделах (ЛК: lk.sk.ru)
- [ ] **Устав** по шаблону Фонда с файлом из налоговой
- [ ] **Презентация** проекта (рекомендуется)
- [ ] **Подтверждающие документы** (протоколы, отчёты, патенты)

## Перед подачей

- [ ] Описание "упаковано" в формат **"просто, инновационно, перспективно"**
- [ ] Все 4 раздела заполнены **с конкретикой** (числа, факты, ссылки)
- [ ] Текст **вычитан экспертом** предметной области
- [ ] **Нет противоречий** между разделами
- [ ] Выбран путь подачи: [ ] Самостоятельно (~20 дней) / [ ] Fast Track (12-14 дней, 190 000 руб.)

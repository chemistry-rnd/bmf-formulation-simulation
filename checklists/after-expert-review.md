# Чеклист: обработка замечаний эксперта

> После получения обратной связи от эксперта — систематическая обработка замечаний.

## Приём замечаний

- [ ] **Все замечания собраны** в единый список (из комментариев, писем, устных заметок)
- [ ] **Каждое замечание пронумеровано** и классифицировано:
  - Фактическая ошибка (приоритет: высокий)
  - Неточность / упрощение (приоритет: высокий)
  - Нехватка данных (приоритет: средний)
  - Стилистическое / терминологическое (приоритет: низкий)
  - Структурное / порядок разделов (приоритет: низкий)

## Обработка (для каждого замечания)

- [ ] **Понял суть замечания** — если неясно, переспросил эксперта
- [ ] **Определил затронутые разделы** — одно замечание может влиять на несколько мест
- [ ] **Нашёл данные для исправления** — или запросил дополнительные данные
- [ ] **Внёс правку** в текст описания
- [ ] **Проверил непротиворечивость** — правка не конфликтует с другими разделами
- [ ] **Пометил замечание как обработанное**

## Проверка после правок

- [ ] **Все замечания обработаны** — не осталось пропущенных
- [ ] **Числа обновлены везде** — если изменился параметр, обновлён во всех местах (текст + таблицы)
- [ ] **Нет "висячих" ссылок** — если удалён раздел, убраны ссылки на него
- [ ] **Перечитал весь документ** — после точечных правок текст читается цельно
- [ ] **Нет новых абстракций** — правки не добавили расплывчатых формулировок

## Документирование

- [ ] **Сохранён лог изменений** — что было → что стало → почему
- [ ] **Отправлено подтверждение эксперту** — список обработанных замечаний
- [ ] **Отмечены open items** — замечания, которые не удалось закрыть сейчас (нужны доп. данные)

## Повторная вычитка (если нужна)

- [ ] **Изменения существенные** — если >30% текста переписано, стоит показать эксперту ещё раз
- [ ] **Новые разделы добавлены** — эксперт не видел этот текст
- [ ] **Конфликтующие замечания** — от разных экспертов, нужно согласовать

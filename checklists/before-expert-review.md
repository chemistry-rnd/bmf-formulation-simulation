# Чеклист: перед отправкой эксперту

> Проверьте описание технологии перед тем, как передать его на экспертную вычитку.

## Полнота содержания

- [ ] **Описание процесса** — все этапы перечислены и описаны
- [ ] **Модульная структура** — технология разбита на логические модули/этапы
- [ ] **Номенклатура** — указаны группы продуктов/объектов, если применимо
- [ ] **KPI процесса** — параметры с числовыми значениями (не "хороший", а "85-90%")
- [ ] **KPI продукта** — показатели до/после с единицами измерения
- [ ] **Методы контроля** — указаны конкретные методы, стандарты, частота
- [ ] **Результаты НИОКР** — описаны проведённые исследования с подтверждениями
- [ ] **Конкуренты** — сравнительная таблица минимум с 2 аналогами

## Качество данных

- [ ] **Числовые диапазоны** — вместо точечных значений даны min-max по батчам
- [ ] **Разделение по осям** — KPI разделены по измерениям (напр. внешний vs внутренний)
- [ ] **Единицы измерения** — у каждого числа указана единица
- [ ] **Источники** — для рыночных данных указаны источники
- [ ] **Нет абстракций** — заменены все "значительно улучшает", "существенно снижает" на конкретику

## Структура и читаемость

- [ ] **Заголовки** — структура логична, разделы не перекрываются
- [ ] **Таблицы** — сложные данные представлены в табличном виде
- [ ] **Длина** — каждый раздел 1-3 абзаца (не простыня текста)
- [ ] **Терминология** — термины используются консистентно
- [ ] **Аббревиатуры** — расшифрованы при первом упоминании

## Пометки для эксперта

- [ ] **Отмечены неуверенные места** — где данные приблизительные, помечено "~" или "требует уточнения"
- [ ] **Вопросы к эксперту** — сформулированы конкретные вопросы в конце документа
- [ ] **Формат обратной связи** — указано, в каком виде ожидаете замечания (комментарии в документе / список / встреча)

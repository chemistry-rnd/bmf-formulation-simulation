# Чеклист: сбор данных с производства

> Какие данные собрать у предметного специалиста / на производстве для описания технологии.

## Приоритет 1: Без этого описание не написать

### Процесс
- [ ] **Перечень этапов** процесса (от сырья до готового продукта)
- [ ] **Ключевые параметры** каждого этапа (температура, время, давление, концентрация)
- [ ] **Числовые диапазоны** параметров (min–max по батчам, а не "около")
- [ ] **Критические точки** — где сбой параметров критичен

### Продукт
- [ ] **Характеристики готового продукта** с числами (прочность, вязкость, срок годности и т.д.)
- [ ] **Сравнение до/после** — что было без технологии и что стало
- [ ] **Методы измерения** — как именно измеряете каждый показатель

### Результаты
- [ ] **Данные экспериментов** — протоколы, таблицы, графики
- [ ] **Количество проведённых батчей / испытаний**
- [ ] **Воспроизводимость** — разброс результатов между батчами

## Приоритет 2: Нужно для полного описания

### Сырьё
- [ ] **Список компонентов** с дозировками
- [ ] **Функция каждого компонента** — зачем добавляется
- [ ] **Поставщики** — кто поставляет, есть ли альтернативы
- [ ] **Стоимость** основных компонентов

### Оборудование
- [ ] **Список оборудования** по этапам
- [ ] **Стандартное vs специализированное** — что нужно докупить/разработать
- [ ] **Производительность** — кг/час, единиц/смена

### Контроль качества
- [ ] **Перечень контрольных точек** (in-line и off-line)
- [ ] **Стандарты** — ГОСТ, ISO, ТР ТС, которым соответствует
- [ ] **Сертификаты / протоколы** — уже полученные

### Масштабирование
- [ ] **Текущий масштаб** (лабораторный, пилот, промышленный)
- [ ] **Min/max размер батча**
- [ ] **Барьеры масштабирования** — что мешает увеличить объём
- [ ] **Требования к помещению** (площадь, класс чистоты, вентиляция)

## Приоритет 3: Для заявки в фонд / инвестору

### Экономика
- [ ] **Себестоимость** единицы продукции (или оценка)
- [ ] **Основные статьи затрат** (% от себестоимости)
- [ ] **Целевая цена** для потребителя
- [ ] **Данные по рынку** — объём, рост, ключевые игроки

### IP
- [ ] **Патенты** (поданные и полученные) — номера, даты
- [ ] **Ноу-хау** — что нельзя раскрывать
- [ ] **Публикации** команды по теме
- [ ] **Регуляторные разрешения** — полученные или требуемые

### Команда
- [ ] **CV ключевых участников** (образование, опыт, достижения)
- [ ] **Список публикаций** и патентов команды
- [ ] **Партнёры** — институты, лаборатории, производства

## Формат сбора данных

| Способ | Когда использовать |
|--------|-------------------|
| **Анкета** (шаблон: `templates/expert-questionnaire.md`) | Первичный сбор, специалист далеко |
| **Интервью** (30-60 мин) | Сложная технология, много нюансов |
| **Визит на производство** | Нужно увидеть процесс, собрать фото/видео |
| **Запрос документов** | Протоколы, сертификаты, отчёты — просто попросить |

## Типичные проблемы при сборе

| Проблема | Решение |
|----------|---------|
| "Это коммерческая тайна" | Обсудить NDA; указать "ноу-хау" без раскрытия деталей |
| "Точных данных нет" | Попросить оценочные с пометкой "~"; запросить диапазон |
| "Данные в разных форматах" | Предоставить шаблон таблицы для заполнения |
| "Нет времени на анкету" | Провести интервью и заполнить самому |

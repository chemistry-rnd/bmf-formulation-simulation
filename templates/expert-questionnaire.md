# Шаблон анкеты для предметного специалиста

> Цель: собрать с производства / лаборатории конкретные данные для описания технологии.
> Две версии: минимальная (быстрый старт) и расширенная (полное описание).

---

## Инструкция для заполняющего

- Отвечайте конкретно: числа, диапазоны, единицы измерения
- Если точных данных нет — укажите оценочные с пометкой "~" или "оценка"
- Если вопрос неприменим — напишите "Н/П" с пояснением
- Приложите фото, протоколы, отчёты где возможно

---

## Часть 1: Минимальная анкета (15 мин)

### 1.1 Общее

1. Как называется технология / продукт / процесс?
2. Какую задачу решает? Для кого?
3. На какой стадии находится? (идея / лаборатория / прототип / пилот / серия)
4. Есть ли аналоги на рынке? Чем отличается ваше решение?

### 1.2 Процесс

5. Опишите основные этапы процесса (3-7 шагов):
   - Этап 1: [...]
   - Этап 2: [...]
   - ...
6. Какое оборудование используется на каждом этапе?
7. Какие ключевые параметры нужно контролировать? (температура, время, концентрация и т.д.)

### 1.3 Результаты

8. Какие количественные результаты уже получены? (выход, эффективность, срок годности и т.д.)
9. Какие тесты / испытания проведены?
10. Какие основные проблемы / ограничения на текущем этапе?
